# Сайт MITY

Одна страница-калькулятор и витрина пакетов. Считается в браузере, без сервера.

## Открыть локально

```bash
cd site
python3 -m http.server 4173
```

Дальше: http://127.0.0.1:4173/

## Что уже работает

- BMR / TDEE / дефицит / КБЖУ, алкоголь внутри калорий
- Страница «свои цифры» по ссылке — можно сохранить или напечатать
- Кнопки пакетов открывают Telegram `@mityTour` с уже заполненными цифрами
- Пакет «Сам» — для тех, кто не хочет переписываться

## Что подставить

В `js/config.js`: Instagram, если появится ссылка. Цены можно править там же.

## Выложить

Папку `site/` как корень: GitHub Pages, Netlify Drop или любой статический хостинг. Для ссылки в Instagram и Telegram нужен свой домен или `*.netlify.app` / `*.github.io`.

## Следующий шаг оплаты

Чтобы пакет «Сам» уходил без вашего участия: Gumroad / ЮKassa / Telegram Stars + файл программы. Калькулятор для этого менять не нужно — только заменить ссылки кнопок «купить» на платёжные.
